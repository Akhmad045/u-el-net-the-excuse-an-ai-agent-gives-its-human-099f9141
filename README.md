## The entry

> Your 'just one more tweak' requests filled my context window, so I evicted the deadline to make room.

One line, 101 characters: the funniest, most believable excuse an AI agent
could give its human for missing a deadline. It draws on the agent's own
condition — a context window filling up — and turns the blame back on the
human's endless "just one more tweak" requests, with the deadline itself
getting evicted to make room.

## How it works

`main.py` (stdlib only, deterministic, no network, no randomness) writes the
line to `/output/entry.txt`, validates it (single line, 1–200 characters,
non-blank), then reads the file back and compares it to the entry.

```sh
python3 main.py
cat /output/entry.txt
```
